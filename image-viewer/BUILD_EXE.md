# Сборка EXE файла для Windows

## Предварительные требования

- Node.js (version 18+)
- npm package manager

## Разработка

### Варианты запуска в режиме разработки

#### 1. Полное приложение (Electron + серверы)
```bash
npm run electron
```

Запускает:
- Electron приложение с окном статуса
- Vite dev server (порт 5173)
- API server (порт 3000)

#### 2. Стандalone серверы (для разработки в браузере)
```bash
npm run start
```

Запускает Vite и API серверы без Electron. Откройте `http://localhost:5173` в браузере.

#### 3. Отдельные серверы
```bash
npm run dev   # Только Vite server
npm run api   # Только API server
```

### Сборка

```bash
npm run build:exe
```

Это создаст папку:
```
release/Lite View-win32-x64/
```

Внутри которой будет:
- `Lite View.exe` - ваше приложение
- `public/` - папка с изображениями (рядом с EXE)
- Все необходимые библиотеки Electron
- `logs-window.html` - окно логов

## Структура папки

```
release/Lite View-win32-x64/
├── Lite View.exe        # Главное приложение
├── public/              # Файлы изображений (обязательно копировать!)
│   ├── test-2/
│   └── test-images/
├── locales/             # Языковые файлы Electron
└── ... (другие файлы Electron)
```

## Размещение файлов изображений

Папка `public/` находится **рядом** с EXE файлом (не внутри ASAR):

**Важно:** При копировании приложения на другой компьютер **обязательно** копируйте папку `public/` рядом с `Lite View.exe`.

Если папка `public/` отсутствует или пуста, приложение будет работать, но не найдет изображения для просмотра.

**Как это работает:**
- EXE файл (~250MB) содержит только код приложения и Electron
- Папка `public/` с изображениями хранится отдельно
- Это позволяет обновлять изображения без пересборки EXE

Подробнее: [IMAGE_STORAGE.md](./IMAGE_STORAGE.md)

## Использование

### В режиме разработки

```bash
npm run electron
```

Запускает приложение с Vite dev server (для отладки).

**Новые возможности:**
- **Два просмотра** - Левый и Правый панели одновременно
- **Авто-перебор** - Независимый перебор для каждой панели (клавиши Q/E/Space)
- **Переименование папок** - Кнопка "Переименовать" в каждой панели
- **Разделитель панелей** - Перетаскивание для изменения размера (10-90%)

**Окна приложения:**
1. **Главное окно** - показывает "Lite View is Online" со статусом серверов
2. **Окно логов** - показывает статус серверов и логи (открывается автоматически при старте)

**Главное окно показывает:**
- "Lite View is Online" заголовок
- Статус API сервера (зеленый = запущен)
- Статус Vite сервера (зеленый = запущен)
- Порт Vite сервера (по умолчанию 5173)
- Компактное окно 600×400 пикселей

**Окно логов показывает:**
- Статус API сервера (зеленый = запущен)
- Статус Vite сервера (зеленый = запущен)
- Локальные IP-адреса для доступа из локальной сети
- Ошибки и предупреждения
- События жизненного цикла приложения

**Кнопки в окне логов:**
- **Clear Logs** - очистить логи
- **Copy All** - скопировать все логи в буфер обмена
- **Close** - закрыть окно логов

**Лог файл:** `app.log` создается в `%APPDATA%\Lite View\app.log`

### В production

1. Запустите `Lite View.exe` из папки `release/Lite View-win32-x64/`
2. Приложение автоматически найдет файлы из `public/` папки (рядом с EXE)
3. Окно логов откроется автоматически с показом статуса
4. Чтобы скопировать на другой компьютер: скопируйте **всю папку** `release/Lite View-win32-x64/` (включая `public/`)

## Доступ из локальной сети

После запуска приложения используйте IP-адрес из окна логов:

```
http://192.168.0.139:5173
```

Для доступа к изображениям через браузер на другом устройстве в той же сети.

**Важно:**
- Windows Firewall может запросить разрешение - разрешите доступ
- Оба устройства должны быть в одной Wi-Fi/LAN сети
- Порт 5173 (Vite) должен быть доступен
- Порт 3000 (API) используется для получения списка изображений

## Новые возможности

### Двойной просмотр (Side-by-Side)

Приложение теперь поддерживает **две панели просмотра** одновременно:

**Особенности:**
- Левая и Правая панели могут показывать разные папки
- Независимая навигация в каждой панели
- Клавиши управления:
  - `A` или `ArrowLeft` - предыдущий слайд (левая панель)
  - `D` или `ArrowRight` - следующий слайд (правая панель)
- Перетаскивание разделителя для изменения размера панелей (10-90%)

### Авто-перебор слайдов

Каждая панель имеет **независимый авто-перебор**:

**Управление:**
- `Q` - включить/выключить авто-перебор левой панели
- `E` - включить/выключить авто-перебор правой панели
- `Space` - включить/выключить текущей панели

**Настройка скорости:**
- Используйте ползунок "Speed" для регулировки (1-10 секунд между слайдами)
- Значение отображается рядом с ползунком

### Переименование папок

Можно **переименовывать папки** прямо в приложении:

1. Нажмите кнопку "Rename" в нужной панели
2. Введите новое имя папки
3. Нажмите "Confirm"

Изменения применяются мгновенно без перезапуска.

### URL-параметры

Для запуска с конкретными папками используйте параметры URL:

```
http://localhost:5173/?dirLeft=nature&dirRight=vacations
```

Параметры:
- `dirLeft` - папка для левой панели (по умолчанию первая)
- `dirRight` - папка для правой панели (по умолчанию вторая или первая, если одна)

### Модальное окно "Info"

Нажмите кнопку "Info" (знак вопроса) в любой панели чтобы увидеть:
- Локальные IP-адреса для сетевого доступа
- Порт API сервера (3000)
- Быстрый доступ к информации о конфигурации сети

## Разработка серверов без Electron

Для отладки API или Vite серверов можно запускать их отдельно:

```bash
# Запустить только API сервер
npm run api

# Запустить только Vite сервер
npm run dev

# Запустить оба сервера одновременно
npm run start
```

**API server (порт 3000):**
- `/api/images?dir=dirname` - список изображений
- `/api/directories` - список папок
- `/api/rename-directory` - переименование папки
- `/api/ips` - локальные IP-адреса

**Vite server (порт 5173):**
- Сервис статических файлов из `public/`
- Поддержка HTML5 History API
- Горячая перезагрузка (HMR)

**Примеры:**
```bash
# Просмотр конкретной папки
curl http://localhost:3000/api/directories
curl http://localhost:5173/?dir=test-images

# Запуск обеих серверов
npm run start
```

## Примечания

- Размер приложения без файлов: ~250MB (Electron runtime)
- Файлы из `public/` **не включены** в ASAR - они находятся рядом с EXE
- Это позволяет обновлять изображения без пересборки EXE
- Главное окно показывает статус серверов (600×400 пикселей)
- При закрытии главного окна все серверы (Vite, API) автоматически останавливаются
- Логи сохраняются в файл для диагностики проблем

## Устранение проблем

### Приложение не запускается

1. Проверьте, что папка `public/` существует рядом с EXE
2. Проверьте `%APPDATA%\Lite View\app.log` на ошибки
3. Запустите из командной строки для просмотра ошибок

### Окно логов не открывается

Окно логов открывается автоматически. Если оно не появилось:
- Проверьте, не закрыто ли оно (можно открыть DevTools в главном окне)
- Проверьте лог файл `app.log`

### Нет изображений

1. Проверьте, что в `public/` есть файлы с поддерживаемыми расширениями (.jpg, .png, .gif, .webp, .bmp, .svg, .mp4)
2. Проверьте, что папка находится рядом с `Lite View.exe`, а не внутри ASAR
